# UPI Fraud Statistical Signals

## Problem Statement
This project analyzes UPI transaction data using statistical methods to identify unusual transaction patterns and potential fraud signals.

## Dataset Description
The dataset contains UPI transaction details such as transaction hour, day, month, category, age, transaction amount, state, and fraud risk.

## Statistical Methods
- Descriptive Statistics
- Mean, Median and Standard Deviation
- Quartiles and Percentiles
- Skewness
- IQR Outlier Detection
- Z-Score Outlier Detection
- Independent T-Test

## Fraud Signal Findings
The analysis focuses on:
- High transaction amounts
- Transaction timing
- Transaction categories
- Age groups
- Unusual transaction patterns

## Visual Analysis
The project includes:
- Transaction amount distribution
- Box plots
- Transaction amount vs fraud risk
- Transaction hour vs fraud risk
- Age vs fraud risk
- Category vs fraud risk

## Business Recommendations
- Monitor unusually high-value transactions.
- Apply additional verification for suspicious transactions.
- Monitor unusual transaction hours.
- Monitor categories with higher fraud percentages.
- Use statistical analysis to identify unusual transaction patterns.

## Future Scope
Future work can include machine learning models, real-time fraud detection and additional user/device-level transaction features.
